# Self-hosted fonts

The website uses self-hosted copies of two Google Fonts families:

- **DM Sans** — Copyright 2014 The DM Sans Project Authors
  (https://github.com/googlefonts/dm-fonts)
- **Cormorant Garamond** — Copyright 2015 The Cormorant Project Authors
  (https://github.com/CatharsisFonts/Cormorant)

Both families are licensed under the SIL Open Font License, Version 1.1:
https://openfontlicense.org/

The files were downloaded from Google Fonts (https://fonts.google.com/) and
are limited to the Latin subset used by this website. Self-hosting avoids a
third-party request to Google when visitors open the site.
